# Roadmap

This roadmap describes proposed areas of work. It is not a release schedule, delivery commitment or claim that planned features already exist.

## Existing product foundation

The current application supports market monitoring, derivatives and sentiment indicators, liquidity information, alerts, watchlists and the Scrappy assistant. The approved identity is SCRAPT: **CLARITY IN MARKET CHAOS.**

## Near-term priorities

- Keep public documentation aligned with verified application capabilities.
- Refine explanations of freshness, unavailable data and connection states.
- Review keyboard navigation, responsive layouts and reduced-motion behavior.
- Gather actionable UX feedback from monitoring workflows.
- Define a consistent product glossary and terminology.

## Further product work

- Evaluate information hierarchy and workspace usability through user feedback.
- Improve the clarity and consistency of assistant explanations.
- Expand documentation for supported user workflows when release scope is confirmed.
- Establish a public release and asset-review process before distributing additional materials.

## Publication boundaries

Public application source, packaged downloads, additional assets and licensing decisions are not implied by this roadmap. Each requires a separate decision and review.
