# Project scope and collaboration

## Public repository purpose

`labsscrap-code/scrapt` is the official public documentation and project-presentation repository for SCRAPT.

Its scope is product communication, high-level architecture, UX/UI direction, branding guidance and the roadmap. It does not contain the application implementation or a runnable release.

## Collaborative development

SCRAPT builds on an application developed collaboratively with another engineer. Core backend, scanner, market-intelligence and AI functionality remain the responsibility of the engineer maintaining those systems. UX/UI, frontend presentation, branding and public technical documentation are coordinated alongside that work.

Public documentation does not imply a transfer of ownership, a software license or permission to republish contributors' implementation. Credits and release scope should be confirmed with the relevant contributors before expanding public distribution.

## Materials included here

- Original public-facing product documentation.
- Conceptual architecture diagrams.
- Feature descriptions based on verified functionality.
- Proposed roadmap and approved brand direction.
- Contribution and sensitive-reporting guidance.

## Materials outside this repository

Application source, backend algorithms, internal operational details, credentials, account data, databases, logs, snapshots, executables, archives and build outputs are outside this public repository's scope.

Any future proposal to publish additional code or assets must receive explicit approval and a separate review before it is committed.
